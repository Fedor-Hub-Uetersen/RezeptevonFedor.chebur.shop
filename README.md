# RezeptevonFedor.chebur.shop
# 🍳 Записки на кухне от Фёдора

Добро пожаловать в мой уютный кулинарный дневник! Это авторский сайт, созданный с душой и вниманием к деталям. Здесь собраны проверенные полезные рецепты, идеи для здорового питания, осознанный подход к еде и теплые жизненные истории.

🌐 **Официальный сайт:** [RezeptevonFedor.chebur.shop](https://RezeptevonFedor.chebur.shop)

---

## 🌟 Особенности проекта

* **Здоровое питание и рецепты:** Подробные рецепты блюд с низким гликемическим индексом, полезные завтраки, супы и десерты без вреда для здоровья.
* **Интерактивные карточки:** Удобное раскрытие полных рецептов (ингредиенты и пошаговое приготовление) по одному клику.
* **Видеоистории:** Живые видеоролики и зарисовки с авторской атмосферой.
* **Увеличение фото:** Возможность рассмотреть каждую деталь блюда в высоком разрешении по клику на фотографию.
* **Смена тем и языков:** Поддержка светлой/темной темы и переключения языков (русский / немецкий).
